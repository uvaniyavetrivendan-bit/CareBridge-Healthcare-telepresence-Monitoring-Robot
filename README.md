# CareBridge-Healthcare-telepresence-Monitoring-Robot
IoT- based telepresence robot for remote monitoring, live camera streaming ,obstacle detection ,and patient-status communication

# Overview

CareBridge is an IoT-based telepresence robot project developed to explore remote robot control, live camera monitoring, obstacle detection, and patient-status communication.

The project combines embedded systems and IoT concepts for healthcare-related remote monitoring applications.

# Objectives

- Enable remote robot movement control.

- Support live camera monitoring.

- Detect obstacles and stop robot movement when required.

- Share patient-status information through Telegram.

- Explore low-cost remote monitoring solutions.

# Key Features

- Remote movement control using directional commands.

- Live camera streaming.

- Obstacle detection using a sensor.

- Patient-status communication through Telegram.

# System Workflow

1. The user sends a movement command.

2. The controller processes the command.

3. The robot performs the requested movement when safe.

4. The camera provides a live view.

5. Obstacle information and patient-status updates are communicated as implemented.
